# Help

`help` opens this manual. `help <topic>` jumps to a page. `help building rooms` opens that section of a longer guide.

The list on the left has two groups:

- **Game** — rules for the pack you are playing, from `games/<id>/help/`. This is where names like Grit and Calm are explained.
- **Engine** — the same manuals in every game: playing, commands, items, saves, and building.

Up and down move through that list. A topic with several headings, such as building, opens into sections under its name. Page Up and Page Down scroll the page you are reading. The bar on the right of a pane shows how far through it you are. Esc closes the manual.

`help systems` opens the pack's own rules when that file exists. The engine copy of systems stays in the list under Engine.

From a game's intro screen, choose Help for the same manual. `stats` (also `score`) shows your numbers.
