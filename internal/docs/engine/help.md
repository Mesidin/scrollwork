# Help

Type `help` for a catalog, `help <topic>` to read one.

Builders: `help building` is the pack-authoring guide (files on disk and in-engine commands).

Players: `help playing`, `help systems`, `help items`, `help commands`.

Game docs live in the pack (`games/<id>/help/*.md`). Engine docs ship with Sudengine. A pack file of the same name wins.

From a game's intro screen, choose Help to browse the same files before you start. `stats` (also `score`) shows your numbers; `help systems` explains them.
