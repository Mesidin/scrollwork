# About this house

A small single-player pack for Sudengine: eight rooms, a locked cellar, a lamp, a maid, a rat, and something in the water.

This folder (`help/*.md`) is the **game** manual. Engine-wide topics (`playing`, `building`, `commands`, `saves`) still work — type `help` for the full catalog.

Start with `help house`. Numbers: `stats` then `help systems`. Builders: `help building`.
