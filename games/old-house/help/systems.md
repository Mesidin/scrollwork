# Grit and Calm

This house does not use hit points by that name.

- **Grit** is how much punishment you can take. It is the combat bar. Reckless characters start with more.
- **Calm** is nerve. `steady` spends 3 Calm to recover a little Grit. Careful characters start with more.

`stats` (or `score`) shows both, plus Body/Will and the `steady` action.

They tick back up slowly when you are not fighting. A lamp does not spend either; `use lamp` only makes light.

See engine `help systems` if this file is missing — this pack's copy is the one that names Grit and Calm.
